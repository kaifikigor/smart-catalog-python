УМНЫЙ КАТАЛОГ — запуск на Windows

1. Установите Python 3.10 или новее, если его нет.
2. Дважды нажмите 01_START_PROGRAM.bat.
3. В открывшемся окне нажмите «Обработать таблицы».
4. После обработки откройте отчет в браузере.

02_RUN_DEMO.bat — запускает обработку без графического окна.
Программа работает только с CSV UTF-8, не с XLSX.
