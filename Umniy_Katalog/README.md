# Умный каталог — автоматизация таблиц на Python

**Демонстрационный проект для портфолио.** Программа помогает объединить CSV-таблицы с товарами, которые можно сохранить из Excel, проверить записи, обнаружить дубли и получить готовый каталог и наглядный отчет.

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white) ![Dependencies](https://img.shields.io/badge/зависимости-не%20нужны-207C68)

## Что умеет

- Обрабатывает сразу несколько `.csv`-файлов из одной папки.
- Узнает несколько распространенных вариантов названий столбцов: `Артикул / SKU`, `Наименование / Товар`, `Категория / Группа`, `Цена / Стоимость`, `Остаток / Количество`.
- Убирает лишние пробелы в артикулах, проверяет цены и остатки.
- Находит повторяющиеся артикулы **между файлами**; сохраняет первую корректную запись, а повтор отмечает как ошибку.
- Создает единый каталог `catalog.csv`.
- Создает список проблем `errors.csv` и красивый отчет `report.html`.
- Рассчитывает количество позиций, число проблем, количество товаров и ориентировочную стоимость остатков.
- Не требует оплаты, интернета или сторонних Python-библиотек.

> Важно: версия 1 обрабатывает именно **CSV UTF-8**, а не `.xlsx`. В Excel нужный файл можно сохранить через **Файл → Сохранить как → CSV UTF-8**. Если в таблице формулы, экспортируйте предварительно их рассчитанные значения.

## Запуск на Windows

1. Установите **Python 3.10 или новее** с официального сайта https://www.python.org/downloads/ (если еще не установлен).
2. Скачайте проект и распакуйте архив.
3. Дважды щелкните **`01_START_PROGRAM.bat`** (первый файл в списке). Откроется окно программы.
4. По умолчанию выбраны демонстрационные файлы в папке `example_input` и папка результатов `example_output`.
5. Нажмите **«Обработать таблицы»**. После завершения согласитесь открыть HTML-отчет.

Если окно не открывается, запустите через терминал в папке проекта:

```bash
python app.py
```

Для запуска без окна:

```bash
python catalog_cleaner.py --input example_input --output example_output
```

Папка с исходными таблицами и папка результатов должны отличаться. В папке результатов файлы с такими же названиями могут быть перезаписаны.

## Для каких заказов подходит опыт

Объединение каталогов, приведение данных к единой структуре, предварительная очистка прайс-листов, выявление повторов, автоматизация отчетности и подготовка файлов для Excel. Для заказов с иным форматом или правилами учета логика подстраивается под техническое задание.

## Ограничения

- CSV нужно сохранять в кодировке UTF-8. Разделитель — `;` или `,`.
- Для совпадающих артикулов оставляется первая корректная запись в алфавитном порядке имен файлов; остальные выносятся в список проблем. Программа **не объединяет остатки автоматически**, поскольку одинаковый артикул может обозначать как дубль, так и товар на разных складах.
- Ошибочные записи не попадают в итоговый каталог — их нужно проверить вручную.
- Файлы обрабатываются локально; никакие данные никуда не отправляются.
- Ориентировочная стоимость остатков не является бухгалтерской оценкой запасов.
