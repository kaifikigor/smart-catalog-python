# Умный каталог | Python

**Программа для автоматической обработки товарных таблиц, поиска ошибок и формирования отчетов**

## О проекте

«Умный каталог» — демонстрационное приложение на Python, которое помогает автоматизировать работу с товарными каталогами и прайс-листами.

Программа объединяет несколько CSV-файлов, проверяет корректность информации и формирует готовый отчет.

**Основная цель:** сократить время на ручную обработку таблиц и упростить поиск ошибок в данных.

## Возможности программы

- Объединение нескольких CSV-файлов в один каталог
- Поиск повторяющихся артикулов
- Проверка корректности цен
- Проверка товарных остатков
- Обнаружение пустых артикулов
- Формирование списка ошибок
- Подсчет стоимости товарных остатков
- Создание HTML-отчета со статистикой
- Удобный графический интерфейс для запуска обработки

## Как запустить

1. Скачайте проект с GitHub через **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте папку `Umniy_Katalog`.
4. Убедитесь, что на компьютере установлен Python.
5. Запустите файл `01_START_PROGRAM.bat`.
6. Нажмите кнопку «Обработать таблицы».
7. Откройте сформированный HTML-отчет.
